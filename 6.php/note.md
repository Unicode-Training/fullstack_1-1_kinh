# PHP

## Tổng quan

- PHP ngôn ngữ lập trình bên phía Server (Chỉ chạy trên server, ngôn ngữ Backend)
- Chạy đa nền tảng (Hệ điều hành nào cũng chạy được)
- Ngôn ngữ đồng bộ
- Phần mở rộng .php

## Các cách chạy

- Cách 1: Chạy qua CLI
- Cách 2: Chạy qua HTTP: Phải có WebServer (Apache, Nginx), Built-in web server có sẵn có PHP

```
cd duong-dan-can-chay
php -S localhost:{port}
```

- Test nhanh 1 đoạn code, hàm:

```
php -a
```

```
php -r "lenh php"
```
